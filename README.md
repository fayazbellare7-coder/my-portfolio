## ✨ Website Highlights & Features

- **Smooth Scrolling Engine:** Integrated [Lenis](https://github.com/darkroomengineering/lenis) smooth scrolling synchronized with [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/) via `gsap.ticker` for fluid, momentum-based scrolling.
- **3D Spatial Hero Stage:**
  - Multi-axis rotating orbital rings with dynamic depth.
  - Sculptural 3D layered monogram card with warm sheen and bevel shadows.
  - Floating glassmorphic information cards with backdrop blur.
  - Mouse-reactive 3D parallax on desktop.
- **Interactive Project Cards:**
  - Dynamic 3D tilt perspective responding to cursor position.
  - Bespoke technical SVG and CSS mockups (2D graphics canvas, AI cricket radar pitch, eCommerce interface, database terminal, and 3D isometric layer stack).
  - Editorial asymmetric grid layout.
- **Dynamic Education Timeline:** An animated vertical progress line that draws down as you scroll through academic milestones.

## 💻 Running Locally

To run the portfolio on your local machine:

```bash
# Clone the repository
git clone https://github.com/fayazbellare7-coder/my-portfolio.git
cd my-portfolio

# Start a local static server (using Python)
python3 -m http.server 8000

# Or using Node.js
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your web browser.
